Nmap, atau Network Mapper, adalah perangkat lunak gratis dan sumber terbuka yang dirancang untuk penemuan jaringan dan audit keamanan. Selain digunakan oleh administrator sistem untuk menginventarisasi jaringan, mengelola jadwal peningkatan layanan, dan memantau ketersediaan host atau layanan, Nmap juga memanfaatkan paket IP mentah dengan cara yang inovatif untuk mengidentifikasi host yang tersedia di jaringan. Alat ini mampu mendeteksi detail seperti nama dan versi layanan yang ditawarkan, sistem operasi beserta versinya, jenis filter paket atau firewall yang digunakan, serta berbagai karakteristik lainnya. Meskipun awalnya dikembangkan untuk memindai jaringan besar secara cepat, Nmap juga berfungsi dengan baik untuk menargetkan satu host saja. Nmap kompatibel dengan semua sistem operasi utama, dan paket biner resminya tersedia untuk Linux, Windows, dan Mac OS X. Di luar eksekutif baris perintah klasik, ekosistem Nmap juga mencakup Zenmap sebagai antarmuka grafis canggih untuk melihat hasil, Ncat untuk transfer data dan debugging, Ndiff untuk membandingkan hasil pemindaian, serta Nping untuk analisis respons dan generasi paket.
