Nmap, atau Network Mapper, adalah perangkat lunak gratis dan sumber terbuka yang dirancang untuk penemuan jaringan dan audit keamanan. Selain digunakan oleh administrator sistem untuk menginventarisasi jaringan, mengelola jadwal peningkatan layanan, dan memantau ketersediaan host atau layanan, Nmap juga memanfaatkan paket IP mentah dengan cara yang inovatif untuk mengidentifikasi host yang tersedia di jaringan. Alat ini mampu mendeteksi detail seperti nama dan versi layanan yang ditawarkan, sistem operasi beserta versinya, jenis filter paket atau firewall yang digunakan, serta berbagai karakteristik lainnya. Meskipun awalnya dikembangkan untuk memindai jaringan besar secara cepat, Nmap juga berfungsi dengan baik untuk menargetkan satu host saja. Nmap kompatibel dengan semua sistem operasi utama, dan paket biner resminya tersedia untuk Linux, Windows, dan Mac OS X. Di luar eksekutif baris perintah klasik, ekosistem Nmap juga mencakup Zenmap sebagai antarmuka grafis canggih untuk melihat hasil, Ncat untuk transfer data dan debugging, Ndiff untuk membandingkan hasil pemindaian, serta Nping untuk analisis respons dan generasi paket.

Meskipun Nmap telah berkembang pesat dari segi fitur selama bertahun-tahun, fungsi utamanya tetap sebagai pemindai port yang efisien. Perintah dasar `nmap <target>` secara default memindai 1.000 port TCP pada host tujuan. Berbeda dengan banyak pemindai lain yang hanya mengkategorikan port sebagai "terbuka" atau "tertutup", Nmap menawarkan klasifikasi yang lebih rinci dengan membagi port ke dalam enam status: open, closed, filtered, unfiltered, open|filtered, dan closed|filtered. Penting untuk dicatat bahwa status ini bukan sifat bawaan dari port itu sendiri, melainkan representasi dari bagaimana Nmap mendeteksi dan menafsirkan respons port tersebut. Sebagai ilustrasi, pemindaian dari jaringan lokal mungkin menampilkan port 135/tcp sebagai "open", sementara pemindaian bersamaan melalui internet bisa saja melaporkannya sebagai "filtered".

Berikut adalah penjelasan mengenai keenam status port tersebut:

*   **Open**: Pada status ini, aplikasi aktif menerima koneksi TCP, datagram UDP, atau asosiasi SCTP. Menemukan port terbuka sering kali menjadi tujuan utama pemindaian karena bagi penyerang, setiap port terbuka merupakan celah potensial untuk eksploitasi. Sebaliknya, administrator berusaha melindungi atau menutupnya tanpa mengganggu pengguna sah. Port terbuka juga relevan untuk pemindaian non-keamanan karena mengidentifikasi layanan apa saja yang tersedia di jaringan.
*   **Closed**: Port dapat diakses (menerima dan merespons paket probe Nmap), namun tidak ada aplikasi yang mendengarkan lalu lintas di sana. Status ini berguna untuk penemuan host (menunjukkan bahwa IP aktif) dan deteksi sistem operasi. Karena port tertutup masih dapat dijangkau, administrator mungkin mempertimbangkan untuk memblokirnya lewat firewall agar statusnya berubah menjadi "filtered".
*   **Filtered**: Nmap tidak dapat menentukan apakah port terbuka karena penyaringan paket menghalangi probe untuk mencapainya. Penyaringan ini bisa berasal dari perangkat keras firewall khusus, aturan router, atau software firewall host. Status ini menyulitkan penyerang karena minim informasi. Meskipun kadang merespons dengan pesan error ICMP, filter yang diam-diam menjatuhkan paket tanpa respons lebih umum terjadi, sehingga memaksa Nmap melakukan percobaan ulang berulang kali dan memperlambat proses pemindaian secara signifikan.
*   **Unfiltered**: Port dapat diakses, tetapi Nmap belum bisa memastikan apakah status sebenarnya adalah "open" atau "closed". Klasifikasi ini hanya muncul saat menggunakan ACK scan yang bertujuan memetakan aturan firewall. Untuk memperjelas status sebenarnya, pemindaian lanjutan dengan tipe Window, SYN, atau FIN scan mungkin diperlukan.
*   **Open|filtered**: Status ambigu ini digunakan ketika Nmap gagal membedakan antara port yang "open" dan "filtered". Hal ini terjadi pada jenis pemindaian di mana port terbuka tidak memberikan respons sama sekali. Ketiadaan respons bisa berarti port tersebut terbuka namun sunyi, atau paketnya dibuang oleh filter. Tipe scan seperti UDP, IP protocol, FIN, NULL, dan Xmas menghasilkan klasifikasi ini.
*   **Closed|filtered**: Ini adalah status terakhir yang menunjukkan ketidakmampuan Nmap dalam menentukan apakah port "closed" atau "filtered". Status ini sangat spesifik dan hanya digunakan dalam metode IP ID idle scan.
