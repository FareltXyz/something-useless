## Cara Instalasi

*  Instal software obsidian markdown melalui web resmi [obsidian.md](https://obsidian.md/download)
*  lakukan clone repo ini (jalankan di folder yang ingin di taruh)

```sh
git clone https://github.com/FareltXyz/something-useless.git
git submodule init
git submodule update
```

* lalu import di obsidian
